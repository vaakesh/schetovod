# Как повторить замер распознавания

1. Возьми локальный набор из `DOCUMENTS` в `api-measure/run.py` (10 накладных, 12 исходных JPEG). Используй прежний `reference.json`, правила `reference-notes.md` и поправки из `astra-medium/differences.csv`.
2. В `main()` добавь новый ключ прогона для точного API ID модели и уровня reasoning. Для другого поколения учти префикс `gpt-6.2-` в сборке ID. Из корня репозитория выполни `PYTHONPATH=app app/.venv/bin/python api-measure/run.py НОВЫЙ_КЛЮЧ`. Скрипт последовательно обработает все документы штатным распознавателем сайта. Сохрани тот же промпт, схему и лимиты увеличения.
3. По каждой накладной в `runs/НОВЫЙ_КЛЮЧ/` сверь SHA-256 с прошлым прогоном и возьми секунды и результат валидации из `measurement.json`. Сложи usage всех раундов из `trace.json`. Для цены Standard посчитай обычный вход (вход минус чтения и записи кеша), чтения, записи по сроку и весь выход по тарифам модели. Reasoning уже входит в выход.
4. Сопоставь `output.json` с эталоном по напечатанному номеру строки. Сравни числа по значению, повторные пробелы сведи к одному. В исходном замере оценивали 875 полей из 897. Сохрани CSV и краткий отчёт в отдельной папке по образцу `astra-medium/` и сравни ошибки, стоимость, среднее и медиану времени.
